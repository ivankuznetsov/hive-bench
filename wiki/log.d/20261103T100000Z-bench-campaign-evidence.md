# Keep campaign admission and publication on current generation evidence

JudgeSlate uses the shared execution and evidence predicates. In permissive
campaigns an unsuccessful diagnostic record follows the manual missing-cell
route; strict campaigns reject it before any judge call. Quota-backed gaps on
eligible, bound generations retain the existing cooldown routing.

Generate preserves the active root and paid same-generation backfill, skips
retired per-cell snapshots, and supplies explicit replacement snapshots before
judge-only overlays. Deliberation transcripts and skip/union keys include the
generation, artifact bindings and evaluation context. Publication recomputes
admissible-only judged/gated summaries and displays attempted, eligible,
evaluated and diagnostic coverage with unavailable scores and preliminary
labels. Standalone summaries use the same admission rules.
